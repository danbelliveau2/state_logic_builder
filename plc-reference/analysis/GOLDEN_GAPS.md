# Golden Gaps — recurring station types/variations lacking template coverage

> **Naming note (2026-09-23):** the chassis template cited below as `ChassisStandard.L5X` is now `ChassisStandard_1UP.L5X`; the two-up variant is `ChassisStandard_2UP_*.L5X`. Citations keep the name used on the date they were written.

- (2026-08-23, from _1028_Diamond_041024.L5X) N-identical parallel process cells (10 aging/test positions with per-cell probes, Z-axis, timers and pass/fail) served by shared load/unload robots — no template for one parameterized station shape driving N instances
- (2026-08-23, from _1028_Diamond_041024.L5X) Shared part-tracking array shifted head-by-head across a large indexing dial (40 heads) with per-station attempt/success/failure-code stamping — no golden example of who owns and who shifts that array
- (2026-09-01, from _1086_Steris_Cable.L5X) Continuous material-feed station: geared master/slave puller pair with dancer/tensioner-regulated reel payout (VFD + IO-Link distance sensors) — no template covers gearing setup, slip detection or dancer regulation
- (2026-09-01, from _1086_Steris_Cable.L5X) In-line laser process device (IPG fiber laser cut/weld) as a station: bring-up chain, job/group selection strobes, fire strobe and did-not-fire fault
- (2026-09-02, from _990_Beckett_011224.L5X) Rotary dial-index machine: indexer program (servo index + shot-pin lock + all-stations-OK-to-index gate + per-head part tracking) with N per-station programs hanging off it — no template covers the indexer/station handshake shape
- (2026-09-02, from _990_Beckett_011224.L5X) Laser marker station (message-ID/ACK ASCII protocol device) — no golden example
- (2026-09-02, from _990_Beckett_011224.L5X) Robot-tended flex/vibratory feeder cell (robot SM + VFD conveyor + incline + bin gantry as one station) — recurring across 990's three feeders with no template
- (2026-09-03, from SoftwareStandardization.L5X) Outfeed/downstream-conveyor handshake: S18_RejectUnload and S19_GoodUnload both leave the 'wait for outfeed ready' transition as g_MachineBasic.AlwaysOff — there is no template coverage for a station handing a part to a non-dial downstream device (chute full, conveyor ready, tray indexer), which recurs on nearly every unload station.
- (2026-09-04, from EE Hardware Specification Regulations.extracted.md) GuardLogix safety task/program — no template or exemplar showing safety program naming, routine layout, or how station programs consume mapped safety status
- (2026-09-04, from EE Hardware Specification Regulations.extracted.md) SMC EX600 on-machine IO node (including its IO-Link submodule) — no exemplar showing device naming and parameter mapping for a manifold that is both valve bank and IO block
- (2026-09-07, from ShowRoomFlexFeeder.L5X) Flex-feeder conveyor group (Kinetix process conveyor + 2 VFD conveyors + vibratory feeder + vision lights) — a run/stop utility state machine with no per-part cycle; no template covers it.
- (2026-09-07, from ShowRoomFlexFeeder.L5X) Fanuc robot-program supervisor station (PLC starts/pauses/stops/recipe-selects a robot program rather than stepping per-part motions) — no template.
- (2026-09-08, from ChassisStandard.L5X) Cam-driven chassis machine: no golden coverage for the mechanism program (runtime MCCP cam profile + MAPC dial + resync excursion + hand-crank mode) or for angle-window stateless stations (Chassis_CamPos_Check with timing advance) — today's generator only emits state-machine stations.
- (2026-09-08, from ChassisStandard.L5X) Empty-nest / part-left-behind verify station (S20 shape: probe read at an angle, fault on a single consecutive failure) and machine-level cleanout/run-out mode (HMI latch + per-station CycleStation inhibit + all-nests-empty stop trigger) have no template coverage.
- (2026-09-09, from ShowRoomChassis.L5X) Chassis with a SINGLE combined good/reject unload station (no reject chute) — templates ship S18 reject + S19 good as separate stations, so the combined counter/clear rung has no template coverage
- (2026-09-09, from ShowRoomChassis.L5X) Two-speed chassis (standard/fast HMI toggle driving jog MCD plus a speed-dependent OEE IdealCycleTime) — no template shows the speed-mode publication and its Production consumer
- (2026-09-10, from MagnetDial_description_by_Dan.txt) Stack-fed / demand-index dial indexer (fixture holds a stack, upstream stack-present look-ahead, bounded search index with revolution-guard fault) — no template variant covers it; S00_IndexerSP/NoSP both assume one part per nest per index.
- (2026-09-10, from MagnetDial_description_by_Dan.txt) Pneumatic stack-strip escapement head with retract-sensor-only cylinders and a rotary+linear+vacuum pick head handing off to an external robot — recurring shape (MagnetDial, MidBaseLoad) with no template station.
- (2026-09-18, from OEE.L5X) Changeover/multi-product stations: no template shows how PlannedProductionTime is reduced for planned changeover/batch switch when the Recipe program and batch counter are in use, so OEE on recipe-driven machines is computed inconsistently.
