DEVICES
- Magnet Dial — Rotary servo indexer, 10 fixtures, 36° index
- Stack Present Sensor — Verifies fixture holds a magnet stack
- Vertical Shuttle Cylinder — Raises shuttle bar with single magnet
- Horizontal Shuttle Cylinder — Strips one magnet off the stack
- Hold Down Cylinder — Presses stack down; stays extended while stripping
- Top Retainer Cylinder — Holds magnet flat during horizontal strip
- Magnet In Place Sensor — Confirms stripped magnet at pick position
- Pick Rotary Actuator — Swings pick head between pick and robot
- Pick Linear Cylinder — Drives vacuum cup down onto magnet
- Vacuum Cup — Holds magnet through pick and transfer
- Vacuum_Verify_Sensor — Digital Sensor / PEC
- Magnet_In_Position_To_Robot — Parameter
- Robot_Clear — Parameter
- Strip_Retry_Counter — Parameter
- Reject_Flag — Parameter
- Magnet_Ready — Parameter
- Robot_In_Position — Parameter
- Empty_Fixture_Counter — Parameter
- Pick_Retry_Counter — Parameter

SEQUENCE
1. Index dial 36° to next magnet stack
2. Index past any fixture with no stack
3. Extend hold down; stays extended while stripping this stack
4. Raise vertical shuttle cylinder
5. Extend top retainer over magnet
6. Extend horizontal shuttle, strip one magnet
7. Retract top retainer
8. Magnet-in-place sensor confirms; set magnet-ready bit
9. Wait for pick sequence
10. Rotate pick head clockwise to pick position
11. Extend pick cylinder down onto magnet
12. Turn vacuum on, grab magnet
13. Retract pick cylinder clear of shuttle
14. Verify magnet gone from shuttle position
15. Shuttle retracts and strips next magnet, then waits
16. Rotate counterclockwise to robot place position
17. Extend pick cylinder
18. Signal robot: magnet in position for pickup
19. Wait for robot in-position signal
20. Vacuum off, release magnet to robot
21. Wait for robot clear signal
22. Retract pick cylinder
23. Rotate back to pick for next magnet

FAILURE HANDLING
- Fixture at station has no stack → Index dial past it, keep indexing until a stack is present
- Full dial revolution with no magnets anywhere → Flag a reject and fault the machine
- Horizontal shuttled over but no magnet in place → Retract horizontal and try the strip again (retries: 3; when exhausted: Retract everything clear, index dial to next stack with magnets, restart)
- Vacuum on at pick but magnet not grabbed → Retract and retry the pick (when exhausted: Index dial to the next stack and start over)
- Magnet dropped after pick → Check if magnet still in fixture — if yes retry the pick, if no get another magnet
- Any retry path exhausted → Move on to the next stack rather than stopping the machine

STATION INTERACTIONS
- Robot (external, not shown): We signal magnet in position at place; robot signals in position
- Robot (external, not shown): Vacuum off on robot in-position; retract and rotate back only on robot-clear
- Robot (external, not shown): No robot interaction with the shuttle — pick head only

IO & PNEUMATICS (optional capture)
- sensor: Stack present / stack full verify — At the dial position before the work station
- sensor: Magnet in place — Confirms stripped magnet at pick position
- sensor: Vertical shuttle retract
- sensor: Horizontal shuttle retract
- sensor: Top retainer retract
- sensor: Hold down retract
- sensor: Vacuum verification — Confirms magnet grabbed / detects drop
- valve: Vertical shuttle extend/retract
- valve: Horizontal shuttle extend/retract
- valve: Hold down extend/retract
- valve: Top retainer extend/retract
- valve: Pick linear cylinder extend/retract
- valve: Pick rotary clockwise/counterclockwise
- valve: Vacuum on/off
- All four shuttle-section cylinders are retract-sensor only
